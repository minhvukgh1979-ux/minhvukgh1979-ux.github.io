Cấu hình tài khoản Google Drive

Có thể thêm nhiều tài khoản (mỗi tài khoản = 1 folder Drive). Phim trùng tên ở nhiều tài khoản sẽ tự gộp làm 1 - khi 1 tài khoản bị giới hạn (quota), app tự nhảy sang tài khoản khác phát tiếp, không cần chọn lại.

➕ Thêm Google Account mới
Quy trình này tạo cấu hình riêng cho chính Google Account mới. API Key sẽ lấy từ Google Cloud Project của account đó, không dùng Key của account khác.
1. Account 2. Project 3. Drive API 4. API Key 5. Folder 6. Hoàn tất
1

Nhập Google Account mới

Nhập Gmail/Google Account mà bạn muốn dùng cho nguồn phim mới.

⚠ Đây là account sẽ được dùng để tạo/chọn Google Cloud Project và API Key ở các bước sau.
2

Mở Google Cloud bằng account mới

Hãy chắc chắn trình duyệt đang đăng nhập đúng: .

3

Bật Google Drive API

Trong Project vừa tạo/chọn, mở Google Drive API và bấm Enable nếu Google yêu cầu.

4

Tạo API Key cho Project của account mới

Mở Credentials → Create credentials → API key. Sau khi Google hiện Key, copy Key đó.

🔐 App không thể tự tạo API Key trong Google Cloud thay bạn. Bạn chỉ cần thực hiện thao tác Create credentials và dán Key vào đây.
5

Gắn Folder Drive của account mới

Folder nên nằm trên Drive của và chia sẻ Bất kỳ ai có đường liên kết → Người xem.

✓

Hoàn tất account mới

🔐 Cấu hình Google OAuth Client ID
Quy trình này giúp app được Google cho phép đọc và ghi file app-config.json trên Drive. Làm từng bước ngay trong app; bước nào cần thao tác trên Google Cloud thì app có nút mở đúng trang.
1. Account 2. Project 3. Drive API 4. Consent 5. Client ID 6. Origin 7. Nhập vào app 8. Kiểm tra
1

Nhập Google Account

Nhập đúng Google Account sẽ dùng để quản lý Google Cloud Project và cấp quyền Drive cho app.

⚠ Hãy dùng đúng account này ở các bước Google Cloud tiếp theo.
2

Chọn hoặc tạo Google Cloud Project

Đăng nhập Google Cloud bằng , sau đó chọn Project hiện có hoặc tạo Project mới.

3

Bật Google Drive API

Trong đúng Project vừa chọn, mở Google Drive API và bấm Enable nếu chưa bật.

4

Cấu hình OAuth consent screen

Vào OAuth consent screen. Nếu Google yêu cầu, tạo/cấu hình màn hình xin quyền. Với app cá nhân/testing, thêm chính Google Account sẽ dùng app vào Test users nếu Google yêu cầu.

5

Tạo OAuth Client ID

Vào Credentials → Create credentials → OAuth client ID. Chọn Web application.

Application type: Web application
Sau khi tạo, Google sẽ cung cấp một Client ID kết thúc bằng .apps.googleusercontent.com.
6

Thêm địa chỉ GitHub Pages vào Authorized JavaScript origins

Trong OAuth Client vừa tạo, tìm Authorized JavaScript origins và thêm đúng địa chỉ website của app.

Ví dụ: https://minhvukgh1979-ux.github.io. Không thêm dấu / ở cuối.
7

Đưa Client ID vào app

Copy Client ID từ Google Cloud rồi dán vào ô dưới đây.

✓

Kiểm tra quyền Google Drive

App sẽ mở hộp thoại Google. Chọn đúng account và cấp quyền Drive.

✓ Khi báo OAuth thành công, máy này đã sẵn sàng đọc/ghi app-config.json.
☁️ Đồng bộ cấu hình chung qua Google Drive
App có thể lưu toàn bộ account + API Key + folder vào một file app-config.json trong folder Drive dùng chung. Máy khác chỉ cần mở app và đọc file này để có cấu hình mới nhất.
Lưu ý: API Key chỉ có thể đọc/ghi file Drive khi bạn cấp quyền Google cho app; API Key đơn thuần không có quyền ghi Drive.

Mỗi folder phải để chia sẻ "Bất kỳ ai có đường liên kết - Người xem". Muốn tính năng dự phòng hoạt động, các tài khoản nên chứa video CÙNG TÊN file (không cần y hệt 100%, chỉ cần trùng phần tên trước đuôi mở rộng). Nếu có file phụ đề (.srt) cùng tên với video, phụ đề sẽ tự động gắn vào khi phát. Bấm phím M bất cứ lúc nào để mở lại màn hình này.

Sửa hiển thị

Đây chỉ là tên hiển thị trên trang này (lưu trong trình duyệt), không đổi tên file thật trên Google Drive.
