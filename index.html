Cấu hình tài khoản Google Drive

Có thể thêm nhiều tài khoản (mỗi tài khoản = 1 folder Drive). Phim trùng tên ở nhiều tài khoản sẽ tự gộp làm 1 - khi 1 tài khoản bị giới hạn (quota), app tự nhảy sang tài khoản khác phát tiếp, không cần chọn lại.

🧭 Quy trình lấy Google Drive API Key ngay trong app
App không thể tự bấm tạo Key trong Google Cloud vì Google yêu cầu tài khoản của bạn xác nhận quyền. App sẽ làm phần còn lại tối đa: mở đúng trang, hướng dẫn đúng nút, tự nhận/dán Key và kiểm tra ngay.
1
Mở Google Cloud Console

Nếu bạn đã có Project dùng cho API Key hiện tại thì không cần tạo Project mới; bỏ qua bước này.

2
Bật Google Drive API

Trong Project đang dùng, mở Google Drive API và bấm Enable / Bật nếu chưa bật.

3
Tạo API Key

Mở Credentials → Create credentials → API key. Google sẽ hiện chuỗi bắt đầu bằng AIza....

4
Đưa Key vào tài khoản mới

Quay lại dòng tài khoản đang thêm. Dán Key vào ô Google Drive API Key. Nếu app có Key ở tài khoản trước, bấm nút Dùng Key trước để tự điền, không cần tạo Key mới.

5
Kiểm tra và hoàn tất

Nhập tên tài khoản + link folder Drive, rồi bấm 🔍 Kiểm tra folder này. Nếu hiện “✓ OK” thì bấm Lưu cấu hình.

💡 Quan trọng: API Key không gắn riêng với Gmail/Drive. Một Key của Google Cloud Project có thể dùng cho nhiều folder/tài khoản Drive. Bạn chỉ cần tạo Key mới khi muốn tách Project/Key. App không thể tự tạo Key thay bạn vì thao tác này nằm trong Google Cloud và cần quyền đăng nhập của bạn.

Quy trình thêm tài khoản: bấm + Thêm tài khoản → app tự sao chép API Key từ dòng trước nếu có → nhập tên + link folder → bấm 🔍 Kiểm tra folder này → Lưu cấu hình. Nếu chưa có API Key, bấm 🧭 Hướng dẫn lấy API Key trong dòng mới để làm theo từng bước 1→5 ngay trong app. Mỗi folder phải chia sẻ "Bất kỳ ai có đường liên kết - Người xem". Các tài khoản dự phòng nên có video CÙNG TÊN file. Phụ đề .srt cùng tên video sẽ tự động được gắn.

Sửa hiển thị

Đây chỉ là tên hiển thị trên trang này (lưu trong trình duyệt), không đổi tên file thật trên Google Drive.
